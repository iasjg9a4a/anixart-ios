# Changelog

## Unreleased

### Исправлено
- **Kodik теперь играет нативно**: прямой резолв через `kodikplayer.com/ftor` → HLS → AVPlayer
  (ROT+18 + Base64 декодирование `src`), без WebView и прокси. Web-плеер остался запасным путём.
- Источники сортируются так, чтобы нативные провайдеры (Libria/Sibnet/AnixPlayer) шли раньше
  Kodik-WebView: по умолчанию включается тот, что точно проиграется.

### Добавлено
- **Секция «Видео» на странице релиза**: трейлеры, превью, опенинги, эндинги, клипы
  (`video/release/{id}`), встраивания YouTube / VK / RuTube.
- **Секция «Смотреть легально»**: официальные площадки релиза
  (`release/streaming/platform/{id}`) — Netflix и другие, со ссылками в Safari.
- **Автоподбор рабочего источника** (`SourceFallbackService`): если основной плеер
  отвечает ошибкой (Kodik 500), приложение перебирает источники релиза и включает первый рабочий.
- **Офлайн-скачивание** HLS (AniLibria/RuTube/AnixPlayer) через `AVAssetDownloadURLSession`,
  экран «Загрузки», кнопка скачивания в списке серий.
- Тесты: `ReleaseVideoTests` (6), `FallbackTests` (5); всего 7 файлов тестов.

### Исправлено
- `hosting` у видео приходит объектом `{id,name,icon}`, а не строкой — добавлено терпимое
  декодирование (`VideoHostingRef`), иначе падал бы любой релиз с видео.
- Кнопка закрытия плеера получила `accessibilityLabel("Закрыть")` (VoiceOver + UI-тест).
